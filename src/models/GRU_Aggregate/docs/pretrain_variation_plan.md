- **状態：** 計画（未実装）

## 1. 目的と問い

2 か所でデータのバリエーションを増やし、日本への転移がどう変わるかを測る。

- **事前学習（Stage 1）：** ATUS に**土日**と**過去の年**を足す。
- **Stage 2 の教師：** 社会生活基本調査に**別の年**（2016 年）を足す。

| # | 問い | 比べるもの |
|---|---|---|
| Q1 | **事前学習の多様さの効果：** 人数を今と同じに揃えたまま土日や過去の年を混ぜると、日本への転移は良くなるか | `base` と `day_n`、`base` と `year_n` |
| Q2 | **事前学習の人数の効果：** 多様さを揃えたまま人数を増やすと、何が変わるか | `day_n` と `day_all`、`year_n` と `year_all` |
| Q3 | 事前学習に両方を足した上限 | `both_all`（記述だけ） |
| Q4 | **年をまたぐ転移：** 2016 年の教師で当てはめた δ は、2021 年の日本にも効くか | E3 と E0 |
| Q5 | **教師の多様さの効果：** 2016 年と 2021 年を教師にすると、教師に使っていない群が良くなるか | E4 と E2 |

- **背景：**
  - Stage 2 の J3 で、遷移（`bigram_jsd`）と 15 分で終わる活動の割合が ATUS から離れた（[Stage2_results.md](Stage2_results.md) §5.1）。多様なデータで学習した事前分布なら、日本へ寄せるのに要る δ が小さくなり、系列の崩れも小さくなるかもしれない。
  - J5・J6 は 28 群すべてが教師なので循環していて、循環しない証拠は種 42 の E2 だけ（同 §5.4）。E3 は、全国と 28 群の適合を循環させずに測る。
- **wiki での位置づけ：** [[queries/three-open-gaps-hypotheses]] のギャップ②（source を混ぜるのは転移に損か得か）の、国ではなく曜日と年での小さな版にあたる。同ページの仮説は「素朴に混ぜると損、source を条件にすると得」。本計画は、曜日と年を条件にする側を主にする。

## 3. 方法

### 3.1 事前学習の条件の足し方

- **新しい条件：** `day_type`（平日 / 土日）と `year`（2003〜2024、2020 を除く 21 水準）。どちらも埋め込みにして `x` に足す（`domain_embed`）。
- **CFG で落とさない：** 条件を落とす確率 `P_UNCOND` は、今までどおり性・年齢・就業の条件だけにかける。`day_type` と `year` は常に与える。
  - 理由：これも落とすと、条件なしの枝に土日や過去の年が混ざり、g = 1.25 の意味が `base` と変わってしまう。
- **生成：** 常に `day_type = 平日`、`year = 2024` を与える。
- **slot_bias の補正と Stage 2：** `base` と同じ。2024 平日の米国加重の率を目標に g = 1.25 で補正し、そのあと Stage 2 の E0〜E3 を回す。
- **`base` の扱い：** 条件が 1 通りしかないので、`domain_embed` を持たない今の ckpt（`gru_calg125`）と同じ関数を表す。今の結果をそのまま使う。

### 3.2 事前学習の arm

| arm | 学習データ | 学習の人数（目安） | 足した多様さ |
|---|---|---|---|
| `base` | 2024 平日 | 3,363 | なし（今の `gru_calg125`） |
| `day_n` | 2024 平日＋土日を 3,363 人に間引く | 3,363 | 曜日 |
| `day_all` | 2024 平日＋土日 | 約 6,700 | 曜日 |
| `year_n` | 2003〜2024 の平日を 3,363 人に間引く | 3,363 | 年 |
| `year_all` | 2003〜2024 の平日 | 約 12 万 | 年 |
| `both_all` | 2003〜2024 の平日＋土日 | 約 24 万 | 曜日・年 |

- **共通の評価集合：** 2024 平日の検証分割（373 人、今の `sm.split_indices` と同じ人）。どの arm の学習にも入れない。
- **間引き：** 共通の評価集合を除いた残りから、乱数を固定して重複なしで一様に引く。
  - 人数を揃えると、2024 平日の人は減る（`day_n` は約半分、`year_n` は約 100 人）。「同じ人数なら、多様さに回す方が良いか」を問う設計である。
- **種：** 各 arm で 42〜44 の 3 本。E2 と E4（群を外す評価）は種 42 だけで 7 fold。

### 3.3 Stage 2 の教師の年

| 実験 | 教師 | 評価 | 比べる相手 |
|---|---|---|---|
| E3（年をまたぐ） | 2016 年の 28 群 | 2021 年の 28 群と全国の曲線 | E0（Pre-trained）、E1（2021 で当てはめ。循環する上限）、持ち越し |
| E4（教師の年を足す） | 2016 年と 2021 年の 56 行。E2 と同じ 4 群を**両方の年から**外す | 外した 4 群の 2021 年 | E2（2021 年だけで当てはめ） |

- **E3：** 当てはめは今の `calibrate_to_teacher` と同じで、教師だけを 2016 年の A* に替える。
  - **持ち越し：** 2016 年の A* をそのまま 2021 年の予測とみなしたときの誤差。2016 年を完全に再現しても残る誤差、つまり年の間の本当の変化の大きさにあたる。E3 の誤差がこれにどこまで近いかを示す。
- **E4：** δ に年の項を足す：δ = base + sex + age + emp + year[2016]（2021 年を基準の水準にする。1 セルあたり 10 係数）。
  - 反復ごとに、2016 年の行は δ(2016)、2021 年の行は δ(2021) で生成する。生成の量は 2 倍になる。
  - 最後の生成と評価は δ(2021) で行う。
  - 外す群を片方の年だけにすると、その群自身の過去の値が当てはめに入る。そうすると教師の多様さの効果と区別できないので、両方の年から外す。
- **事前学習の arm との組み合わせ：** E3 はすべての arm × 種で回す（T6）。E4 は `base` だけで回し、効いたら他の arm にも広げる。

## 4. 評価（結果を見る前に固定）

| # | 指標 | 何を見るか |
|---|---|---|
| S1 | 共通の評価集合での重み付き NLL（条件は 平日・2024） | Stage 1 の当てはまり（**Stage 1 の主指標**） |
| S2 | 群ごとの時刻別行動者率の MSE（米国加重）と群の分離（`separation_ratio`） | 全国の曲線は補正で揃うので、群で比べる |
| S3 | 系列の指標（`bigram_jsd`・`switch_emd`・`single_slot_ratio` ほか）、Pre-trained | ATUS 2024 平日との距離 |
| S4 | 暗記（exact copy・`dcr_gap`）、最良 epoch | 人数が増えると暗記と過学習が減るか |
| S5 | 生成の多様性（`pairwise_hamming_std`・`pairwise_hamming_iqr`・`group_hamming_mean`・`var_ratio_median`。定義は [plan.md](plan.md) §11.2）、Pre-trained | ATUS 2024 平日との距離。似た系列ばかりにならないか |
| T1 | E0 の 28 群の `rate_mse_split` | Pre-trained がすでに日本にどれだけ近いか |
| T2 | E1 の δ の大きさ（`to_group_bias` の人口加重 RMS） | 日本へ寄せるのに要る移動量 |
| T3 | E1 の J3（`bigram_jsd`・`single_slot_ratio` の実 ATUS との距離） | 系列の崩れ（**転移の主指標その 1**） |
| T4 | E2 の held-out `rate_mse_split`（7 fold） | 教師に使っていない群への転移（**転移の主指標その 2**） |
| T5 | E1 の J4（`bed_bias`・`wake_bias`・`exact_mae`） | 公表表との一致 |
| T6 | E3 の 2021 年への誤差（全国の曲線の MSE・28 群の `rate_mse_split`） | 教師に使っていない年への転移（**転移の主指標その 3、循環しない**） |
| T7 | E4 の held-out `rate_mse_split`（7 fold） | 教師の年を足した効果 |
| T8 | E1 の生成の多様性（S5 と同じ 4 指標）の実 ATUS との距離 | 日本へ寄せたときに多様性が潰れないか |

- 「生成の多様性」は生成した個票どうしの違いの大きさで、Q1・Q5 の「多様さ」（学習データ・教師の種類の多さ）とは別の量。

**判定の規則：**

- **S1〜S3、S5、T1〜T3、T5、T6、T8：** 3 種の中央値で比べる。`base` の 5 種の最小〜最大の外に出たときだけ「差あり」とする。
  - 例：E1 の `bigram_jsd` の `base` の幅は 0.0071〜0.0086。
- **T4・T7：** fold ごとに比べ、7 fold 中 6 以上で小さければ「良い」、1 以下なら「悪い」とする（J2 と同じ基準）。
- **Q1 の結論：** T3・T4・T6 のうち 2 つ以上が `base` より良く、T3・T4・T6・T8 に悪いものがなければ「多様さは転移に効く」とする。逆なら「効かない（損）」とする。それ以外は結論を出さず、値を並べて示す。
- **Q2 の結論：** S1 と T4 で判定する。
- **Q4 の結論：** `base` の 5 種すべてで、E3 の 2021 年への誤差が E0 より小さければ「年をまたいで効く」とする。持ち越しとの比は記述だけにする。
- **Q5 の結論：** T7 を E2 と fold ごとに比べる。

**事前の予測：**

- Q2：人数を増やすと S1 と S4 は良くなる（今は epoch 22 から過学習し、暗記の兆候がある）。
- Q1：S1 は `base` より少し悪くなる（2024 平日の人が減るため）。T3・T4・T6 は予測できない。これが本実験で答える問い。
- Q4：効く。日米の差（米国は日本より就寝が 48 分早いなど）は、日本の 5 年の間の変化より大きいと見込むため。
- Q5：少し良くなる。属性の効果を推定する行が 2 倍になるため。

## 6. 検証

- **a.** 複数年ファイルの 2024 年の部分から作った系列が、今の `atus2024_stula_common12_dataset.csv` と一致する（`TUCASEID` で突き合わせ、全スロット）。一致しない場合は、人数と原因を報告してから進める。
- **b.** 共通の評価集合の `TUCASEID` が、どの arm の学習データにも入っていない。
- **c.** 間引きは、同じ乱数なら同じ人になり、人数が 3,363 になる。
- **d.** `--arm` なしのモデルの出力が、今の ckpt と一致する。
- **e.** `drop_mask` を立てても、`day_type`・`year` の埋め込みは落ちない。
- **f.** 2016 年の表で、20 行動の率の和が各群・各スロットで約 100% になる（`parse_timeband` の既存の検証）。年齢を 7 区分に畳んだあとの群が 28 個揃う。
- **g.** 年の項つきの `fit_additive` が、既知の効果から作った log 比（NaN のセルを含む）から、2 年の δ を復元する。
- **h.** E4 で外した群の行が、2016 年・2021 年のどちらでも当てはめに入っていない。
- Pylance の警告をゼロにする。

## 8. この計画の外

- **素朴に混ぜる arm（`year`・`day_type` を条件にしない）：** wiki の仮説の「損」の側。段 3 の結果を見てから追加を判断する。
- **社会生活基本調査 2011 年以前：** 同じ切り口の表があれば、E3 を 2011 → 2021 にも広げ、年の差が大きいほど誤差が増えるかを見る。
- **社会生活基本調査を事前学習に入れる：** 集計の損失として Stage 1 に入れる案は採らなかった。「米国の個票で事前学習 → 日本の集計で転移」という今の枠組みが変わるため。個票が届いたら、系列として事前学習に入れる案を別に立てる。
- **国を足す（MTUS）：** [[concepts/MTUS]] によれば 25 カ国が調和化されていて、日本は含まれない（韓国が近い）。利用手続きが未確認なので外した。
- **NHTS 2022：** 移動の調査で、家の中の活動を区別できないので外した。
- **日本の土曜日への転移：** 土曜の公表表は 2016 年・2021 年とも e-Stat にある。`day_type` を入れると、将来は生成で土日を指定できる。
