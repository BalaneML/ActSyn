# Stage 1 の過学習指摘に対する反論

対象: `ddpm_simple_pretrain_common12_weekday_20260819.pt`（AggDDPM-Simple の Stage 1 事前学習、
ATUS 2024 平日 N=3,736 / train 3,363 / holdout 373、UNet1D 1,759,124 パラメータ）
測定日: 2026-08-31（初回測定 2026-08-30 を再現）
再現コマンド: `.venv/bin/python3 src/eval/diagnostics/stage1_overfit_check.py --check all`

---

## 0. 要旨

**「Stage 1 は過学習している」という主張を支持する測定結果は存在しない。** 独立な 3 経路
（保持個票の学習目標・暗記・集計）すべてで、holdout の値は **train を同数へ間引いて作った
帰無帯（床）の内側**にある。学習曲線にも過学習の signature（train−val 差の拡大、val の反転上昇）は
出ていない。

ただし本文書は「過学習が無いことの証明」は主張しない。主張するのは次の 2 点である。

1. **過学習の証拠は無い**（3 経路とも床の内）
2. **もし過学習があるなら、その大きさは ε-MSE で相対 +3.4% 未満、DCR で 1 スロット未満**
   （＝ holdout N=373 の検出力の下では、それ以上の過学習は検出されるはずだった）

§8 に、この反論が**認めている 4 つの限界**を明記する。

なお床はブートストラップで作るので、末尾桁は再実行のたびに動く（判定は変わらない）。

## 1. 「過学習」と呼ばれているものを 3 つに分解する

指摘は 1 つの語に見えて、検証手続きの異なる 3 つの主張を含む。まとめて反論すると必ずすれ違うので分ける。

| # | 主張の内容 | 何を測れば決着するか | 本文書の節 |
|---|---|---|---|
| S1 | 学習曲線が過学習の形をしている（early stop したのだから、val が train より低いのは異常） | 学習曲線の train−val 差の推移と、val の傾き | §6 |
| S2 | 訓練個票では良いが、見ていない個票では悪い（汎化していない） | 保持個票の ε-MSE（学習目標そのもの） | §3 |
| S3 | 生成物が訓練個票のコピーである（暗記） | 生成プールから train / holdout への最近傍距離 | §4 |

さらに、測定ではなく前提から来る指摘が 2 つある。

| # | 主張の内容 | 本文書の節 |
|---|---|---|
| S4 | CVAE の Stage 1 は過学習していた。DDPM も同じはずだ | §7 |
| S5 | N=3,363 に 1,759,124 パラメータは多すぎる | §7 |

## 2. 判定規則 — 「train と holdout で値が違う」は差の証拠にならない

3 経路すべてで同じ規則を使う。

- **床（帰無帯）を必ず作る。** train 側を holdout と**同数（373 本）**へ間引いた部分集合で
  同じ統計量を取り直し、その 95% 範囲を床とする。holdout の値がこの床の外に出て初めて差と呼ぶ
- **判定は片側。** 過学習なら「train 側でだけ良い」ので、holdout 側が床より**悪い方向**に
  出たときだけ過学習の証拠になる

この規則が要る理由は実測で示せる。§4 の DCR は、**参照集合のサイズを揃えないと、暗記が
原理的にありえない条件でも +4.13 スロットの「暗記らしき差」が出る**。この 4.13 は全て
参照集合サイズの効果であり、間引くと −0.09 になる。床を置かない比較は、この種の交絡を
そのまま「過学習の証拠」として読んでしまう。

## 3. 経路 A（S2 への反論）— 保持個票の学習目標

学習目標そのもの（ε 予測 MSE）を、**条件付き・t 層化格子 50 点・t ごとに固定したノイズ**で
低分散に測り直す。train と holdout は同じ (t, ε) の組で評価される。

| | ε-MSE |
|---|---|
| train 全体（3,363） | **0.009443** |
| holdout（373） | **0.009639** |
| gap（holdout − train） | **+0.000196** |
| 床: train を 373 本へ間引いた 95% 範囲 | **[0.009132, 0.009754]**（中央 0.009435） |
| 判定 | **床の内。過学習の証拠なし**（片側 p = 0.115） |

t 帯別に床を取り直しても、全 5 帯が床の内側にある。

| t 帯 | train | holdout | gap | 床 | 判定 |
|---|---|---|---|---|---|
| [0, 200) | 0.024016 | 0.024946 | +0.000930 | [0.022983, 0.025114] | 内 |
| [200, 400) | 0.017905 | 0.017974 | +0.000069 | [0.017380, 0.018440] | 内 |
| [400, 600) | 0.004224 | 0.004207 | −0.000017 | [0.004122, 0.004334] | 内 |
| [600, 800) | 0.000727 | 0.000727 | −0.000001 | [0.000716, 0.000739] | 内 |
| [800, 1000) | 0.000344 | 0.000343 | −0.000002 | [0.000342, 0.000347] | 内 |

**読み方**: gap は t < 200（ノイズが薄く、x_t がほぼ個票そのものになる領域）に集中している。
暗記が起きるならまさにこの帯で起きるので、帯別に見ることは指摘に対する最も厳しい確認である。
それでも床を超えない。

**検出力**: 床の上端 0.009754 は train 中央 0.009435 の **+3.4%** にあたる。したがってこの
測定は「相対 +3.4% を超える過学習」を検出できる設計になっており、それが出なかった。
これより小さい過学習の有無は holdout N=373 では判定できない（§8-3）。

## 4. 経路 B（S3 への反論）— 暗記

生成プール `ddpm_simple_pretrain_samples_20260819.csv`（群一様 7,168 本、
チェックポイントと mtime 同一 = 同一ジョブの産物）から、train / holdout への
最近傍ハミング距離 DCR を測る（大きいほど遠い＝暗記していない）。

| | DCR |
|---|---|
| gen → train 全体（3,363） | 22.9177 |
| gen → holdout（373） | 27.0441 |
| **素の gap** | **+4.1264** ← 参照集合サイズの交絡が入っており読めない |
| gen → train を 373 本へ間引き（5 回平均） | 27.1354 |
| **サイズを揃えた gap** | **−0.0914** |
| 床: train 内の互いに素な同数対 8 本 | [−0.3686, +0.9710] |
| 判定 | **床の内。暗記の証拠なし** |

**この行が反論の核心である。** 素の +4.13 を「生成物が訓練個票に 4 スロット分近い＝暗記」と
読むと、過学習ありという結論になる。しかし参照集合を同数へ揃えると −0.09 に消える。
+4.13 は**全て参照集合サイズの効果**であって、モデルの性質ではない。

**完全一致**: 7,168 本中 **2 本**が train のいずれかと 96 スロット完全一致した。中身は
**2 本とも「96 スロット全部 SLEEP_PERSONAL」の定数日記**である。同じ定数日記は実データにも
1/3,736 本存在する自明なモードであり、これは特定個票の暗記ではない。

## 5. 経路 C — 集計（活動別時間シェア）

生成プールを実データの群構成へ重み付けし（`im.group_reweight`）、活動別時間シェアの
差の絶対値和 Σ|Δ|（12 活動合計）を train / holdout に対して測る。

| | Σ&#124;Δ&#124; |
|---|---|
| gen vs train 全体 | 0.1087 |
| gen vs holdout | 0.1370 |
| 床: train を 373 本へ間引き 500 回 | [0.0778, 0.1508]（中央 0.1157） |
| 判定 | **床の内。過学習の証拠なし** |

**この経路は補助的な証拠にすぎない**ことを明記しておく。集計指標は暗記したモデルでこそ
良く見える（訓練集合を再生すれば集計は必ず合う）ので、単独では過学習を否定できない。
経路 A・B が主で、C は「集計側から見ても矛盾しない」という確認である。

## 6. 学習曲線の読み方（S1 への反論）

wandb run `vvc59fjk`（project `domain-transfer-ddpm-agg`）の実測。best_val 0.008111 @ epoch 769、
patience 200 で epoch 969 打ち切り。

### 6.1 「val が train より低いのは異常」— 指標の定義が違うだけである

train 損失と val 損失は**同じ量ではない**。実装（`model.py` `run_epoch`）上の差は 3 つある。

1. **dropout 0.1 は train でのみ有効**（`model.train()` / `model.eval()`）。train 側の損失だけが上がる
2. **train は調査ウェイトによる復元抽出**（`WeightedRandomSampler`）で、val は素の全件
3. **train はエポック内で更新しながらの走行平均**、val はエポック末の重みでの評価。
   下降局面では train の方が必ず古い重みの分だけ高く出る

したがって train と val の**水準の大小関係は情報を持たない**。過学習の signature は
水準の大小ではなく、**差の拡大**である。

### 6.2 train−val 差は拡大していない（＝過学習の signature が無い）

| 区間 | train 平均 | val 平均 | train−val 平均 |
|---|---|---|---|
| epoch [300, 500) | 0.01403 | 0.01336 | +0.000668 |
| epoch [700, 970) | 0.01051 | 0.01021 | +0.000304 |

差の傾きは epoch 500-969 で **−0.000104 / 100 epoch**、700-969 で **−0.000215 / 100 epoch**。
**縮んでいる。**過学習なら拡大するはずの量が、最後まで拡大していない。

### 6.3 val は最後まで反転していない

val の傾きは epoch 700-969 で **−0.000213 / 100 epoch**（なお下降）。上昇に転じた区間は無い。
early stopping が働いたのは「val が悪化したから」ではなく、**改善が min_delta = 1e-4 を
200 エポック連続で下回ったから**である。打ち切りの発生は過学習の証拠ではない。

## 7. なぜ CVAE と結論が違うのか（S4・S5 への反論）

### 7.1 CVAE の過学習は decoder のルックアップ経路によるものだった

japan_match の CVAE Stage 1 では、train_kl ≈ val_kl（encoder は汎化）でありながら
recon だけが乖離した。原因は decoder が (z, d) → 特定の訓練日記のルックアップになれること、
すなわち **96×12 のロジットを 1 本の全結合層で吐く構造**にある。これは AdamW の
weight_decay = 3.0 という異常に大きい値を要した。

**DDPM にはこの経路が無い。** 学習目標は「x_t に混ざったノイズ ε を当てる」ことであり、
同じ個票が毎回**異なる (t, ε) の組**（t は 1000 水準、ε は連続）と対にされる。
1 個票を暗記しても、その個票に対する損失は下がらない（ε は毎回引き直されるため）。
最小化されるのはノイズ条件付き期待値、すなわちスコア関数の平滑な推定である。

**したがって「CVAE が過学習したから DDPM も過学習する」は成り立たない。** 両者は
過学習の経路そのものが異なる。ここを混同すると、不要な対策（wd = 3.0 等）を持ち込むことになる。

### 7.2 パラメータ数と標本数の比は証拠ではない

1,759,124 パラメータ対 N=3,363 という比は、過学習の**リスク指標**ではあるが**証拠ではない**。
実際に過学習したかどうかは保持個票で測るしかなく、それが §3 である。加えて本実装では
dropout 0.1 と CFG 条件 dropout 0.1 が有効であり、拡散の目標は個票 × 1000 t 水準 × 連続ノイズを
張る。パラメータ数だけを根拠にした指摘は、§3 の測定結果に反論できていない。

## 8. 本反論が認める限界

反論の信頼性のために、こちらから先に挙げる。

1. **early stopping は val 分割を使っている。** 厳密には、選択に一度も使っていない
   第 3 分割での検証が残っている（実施には再学習が必要）。ただし選択が働いた対象は
   1 エポックあたり 373 個票 × ランダムな 1 つの t しか引かない**高分散な推定量**であり、
   §3 はその (t, ε) を独立に引き直した低分散推定である。実際 §3 の holdout 値 0.009639 は
   best_val 0.008111 より **0.0015 高い**。これは「best_val が選択によって雑音分だけ楽観側に
   偏っていた」ことを示しており、§3 はその偏りを取り除いた値である
2. **「best epoch 769」は選択根拠にならない。** epoch 700-969 の val は 0.00811〜0.01376 に
   散らばり、トレンド周りの残差 sd は 0.00107。最良点 769 はトレンドから **−2.1σ** の外れ値で、
   実質「700-969 の高原からの無作為抽出」である。したがって論文に「epoch 769 が最良」と書かない。
   汎化性能として引くのは best_val 0.0081 ではなく、低分散推定の **0.0094〜0.0096** である
3. **検出力の限界。** holdout N=373 では、ε-MSE で相対 +3.4%、DCR で約 1 スロットより小さい
   過学習は検出できない。本文書の主張は「その大きさ未満」であって「ゼロ」ではない
4. **train / holdout 分割は層別ではない単純ランダム分割**（`split_indices`、seed 42、10%）。
   28 群のうち最小群では holdout 本数が少なく、群別の過学習は本測定では見えない

## 9. この反論を覆すために必要な測定

指摘側が過学習を主張するなら、次のいずれかを示す必要がある。

- 選択に使っていない第 3 分割で、ε-MSE の gap が床の上端を超えること
- 参照集合サイズを揃えた DCR gap が床の上端を超えること
- 定数日記以外の完全一致・近傍一致が、実データ内の自明モードの率を超えて出ること

いずれも `stage1_overfit_check.py` で測れる（第 3 分割のみ再学習が必要）。
**「値が違う」「early stop した」「パラメータが多い」は、上のどれでもない。**
